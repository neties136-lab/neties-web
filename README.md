# Website Pribadi — Neties

Website pribadi **Neties** — Agen Asuransi Prudential Indonesia & Konsultan Produk COWAY (Surabaya & Sekitarnya).

## 📁 Isi Folder

| File / Folder | Keterangan |
|---|---|
| `index.html` | File utama website (HTML + CSS + JS dalam satu file) |
| `neties-web.jpg` | Foto profil yang dipakai di website |
| `neties-logo.jpg` | Logo shield Neties (navbar, footer & favicon) |
| `uploads/` | Arsip file asli (foto & logo mentah) |

## ⚙️ Cara Edit Isi Website (Panel Admin)

1. Buka **`neties-web.vercel.app/admin.html`** (atau klik link ⚙️ Admin di footer)
2. Masukkan PIN (default: `neties2026` — ganti di file `admin.html` baris `const PIN = ...`)
3. Ubah teks apa pun di formulir → klik **💾 Simpan & Download config.js**
4. Upload `config.js` ke repo GitHub (menimpa yang lama) → website berubah ±30 detik

> ⚠️ Hapus `config.js` lama di folder Downloads sebelum download, supaya tidak jadi `config (1).js`.
> 📷 Ganti foto/logo: upload gambar baru ke GitHub dengan nama sama (`neties-web.jpg` / `neties-logo.jpg`).
