📌 Cara kerjanya (penting dibaca!)

  1. Ubah teks apa pun di formulir bawah ini (semua kolom aman diedit).
  2. Klik 💾 Simpan & Download config.js di bagian bawah.
  3. Upload file config.js itu ke GitHub (repo neties-web → Add file → Upload files → Commit). File lama otomatis tertimpa.
  4. Tunggu ±30 detik — website neties-web.vercel.app otomatis berubah! 🎉
⚠️ Awas jebakan (1) lagi: sebelum download, hapus dulu file config.js lama di folder Downloads, supaya nama file hasil download tetap pas config.js — bukan config (1).js.
📷 Ganti foto / logo? Upload file gambar baru ke GitHub dengan nama yang sama persis (neties-web.jpg untuk foto, neties-logo.jpg untuk logo) — otomatis tertimpa.
